## Members

### DecodeAsync

```csharp
ValueTask<SubtitleFrame?> DecodeAsync(MediaPacket packet);
```

Decode a subtitle packet. No CancellationToken (hot path).

Return `null` indicates **subtitles not produced this time** (data insufficient to form a full article, this package does not contain displayable content,
or the package decoding failure can be skipped), ** does not mean the decoder is invalid—the caller cannot determine the entire failure or discard the decoder based on this
(Consistent with the null semantics of `DecodeAsync`).

**Parameters**

- `packet`: Subtitle packets to be decoded.

**Returns**: Decoded subtitle frames; The semantics of returning `null` are found in remarks.

### FlushAsync
